## Reazlized

- автоматична класифікація звернень клієнтів: бронювання, оплата, housekeeping, харчування, скарги, лояльність, транспорт;
- визначення пріоритету звернення та емоційного забарвлення повідомлення;
- прозора оцінка ризику/аномальності поведінки гостя;
- формування рекомендацій для персоналу готелю;
- генерація шаблону відповіді клієнту;
- підготовка CRM-завдання для Servio/HMS;
- HTTP API для інтеграції з CRM;
- Telegram-сповіщення для важливих звернень.

## Структура

```text
hotel_crm_intelligent_module/
  app.py                         # FastAPI інтеграційний API
  demo.py                        # демонстрація роботи без сервера
  crm_intelligence/
    models.py                    # моделі клієнта, бронювання, звернення, результату
    classifier.py                # класифікація та sentiment scoring
    anomaly.py                   # виявлення аномалій поведінки
    recommender.py               # рекомендації персоналу
    service.py                   # головний інтелектуальний сервіс
    servio_adapter.py            # адаптер до формату Servio/HMS
    telegram_client.py           # відправлення службових повідомлень Telegram
    repository.py                # приклад сховища клієнтів
  data/clients.json              # демо-дані клієнта
```

## Запуск демо

```powershell
python demo.py
```

## Запуск API

```powershell
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

Перевірка:

```powershell
curl http://127.0.0.1:8000/health
```

Приклад запиту:

```json
{
  "request_id": "REQ-1007",
  "client_id": "G-001",
  "channel": "telegram",
  "text": "Терміново! У номері брудно, не працює кондиціонер і я дуже незадоволений сервісом.",
  "created_at": "2026-05-27T15:40:00"
}
```

Endpoint:

```text
POST /analyze-request
```

## Telegram

Для службових сповіщень задайте змінні середовища:

```powershell
$env:TELEGRAM_BOT_TOKEN="token_from_BotFather"
$env:TELEGRAM_ALERT_CHAT_ID="hotel_channel_or_group_id"
```


- CRM/HMS зберігає картку гостя, бронювання, повідомлення та завдання;
- інтелектуальний модуль аналізує вхідне повідомлення;
- результат аналізу повертається як CRM-завдання з виконавцем, пріоритетом, тегами та рекомендаціями;
- важливі події можуть надсилатися у службовий Telegram-канал;
- персонал отримує підтримку прийняття рішень без ручного аналізу всієї історії гостя.
